# Iris Logistic Regression Classification

## Project Overview

This project implements a Logistic Regression classification model using the Iris dataset.

The model is trained to classify Iris flowers into three different species based on their sepal and petal measurements.

## Technologies Used

- Python
- Scikit-learn
- Logistic Regression
- Iris Dataset

## Implementation Steps

1. Load the Iris dataset
2. Encode the target labels
3. Split the dataset into training and testing data
4. Train the Logistic Regression classifier
5. Make predictions on the test data
6. Calculate model accuracy
7. Generate the confusion matrix

## Model Performance

Accuracy: 96.67%
